# u2netp.onnx

U²-Net-p ("U-2-Net small"), a 4.7 MB salient-object segmentation network by
Xuebin Qin et al., "U²-Net: Going Deeper with Nested U-Structure for Salient
Object Detection" (Pattern Recognition, 2020). Source: https://github.com/xuebinqin/U-2-Net.
Released under the Apache License 2.0. This ONNX export is the one distributed
with rembg (https://github.com/danielgatis/rembg, MIT). Aura FX runs it in the
browser with onnxruntime-web (MIT) to find the person in a clip; nothing is
uploaded.
